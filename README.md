# Портфолио мобильного разработчика

Готовый адаптивный сайт-портфолио для **GitHub Pages**. Работает без React, Node.js, npm и установки библиотек: просто загрузите файлы в репозиторий.

## Что есть на сайте

- Главная секция с анимированной композицией из интерфейсов смартфонов.
- Раздел «Обо мне» и карточки принципов работы.
- Карточки проектов и открывающиеся окна с подробностями.
- Технологический стек, контакты, кнопка копирования email.
- Адаптивная мобильная версия, мобильное меню, анимации с учётом сниженной подвижности.
- Локальные SVG-изображения. Никаких внешних зависимостей.

**Важно:** имена PULSE, NORTH и MONO, а также их описания — **примеры вымышленных проектов**, не реальные кейсы. Удалите или замените их перед использованием как профессионального портфолио.

## 1. Как опубликовать на GitHub Pages

1. Создайте репозиторий `ВАШ_ЛОГИН.github.io`. Например, если ваш GitHub-логин `alexdev`, репозиторий должен называться `alexdev.github.io`.
2. Сделайте его **Public**.
3. Загрузите **содержимое** папки сайта (файлы `index.html`, `style.css`, `config.js`, `script.js`, `favicon.svg`, `README.md` и всю папку `assets`) **в корень репозитория**, а не в дополнительную папку.
4. В GitHub откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, затем ветку **main**, папку **/(root)**, нажмите **Save**.
5. Откройте `https://ВАШ_ЛОГИН.github.io`. Публикация может занять несколько минут.

Если сайт не появился, проверьте вкладку **Actions**, название репозитория и наличие `index.html` в его корне.

## 2. Как настроить сайт под себя

Откройте **`config.js`** через GitHub (значок карандаша Edit) и измените:

| Поле | Что изменить |
| --- | --- |
| `name` | Ваше имя |
| `intro` | Короткий текст на главной |
| `about` | Рассказ о себе |
| `email` | Почта, например `me@gmail.com` |
| `github` | Ссылка на ваш профиль GitHub |
| `telegram` | Ссылка на ваш Telegram |
| `skills` | Ваши настоящие технологии |
| `projects` | Ваши настоящие проекты и ссылки на код |

Сохраните через **Commit changes** — сайт обновится автоматически.

### Пример изменения проекта

```js
{
  name: 'MY APP',
  subtitle: 'Короткий заголовок',
  category: 'ANDROID / KOTLIN',
  description: 'Что делает приложение, какие задачи решает, как вы его сделали.',
  image: './assets/my-app.png',
  tags: ['Kotlin', 'Compose', 'Room'],
  features: ['Авторизация', 'Оффлайн-режим', 'Уведомления'],
  repo: 'https://github.com/yourname/my-app',
  demo: false
}
```

Ссылки на GitHub/Telegram и адрес почты в шаблоне специально **оставлены пустыми**. До заполнения кнопки сообщают, что нужно указать контакты, и не ведут на чужие страницы.

## 3. Как добавить фото, GIF и скриншоты приложений

1. Загрузите картинки в папку **`assets`** своего репозитория, например `assets/my-app.png`, `assets/me.jpg`, `assets/preview.gif`.
2. В нужном проекте в `config.js` напишите `image: './assets/my-app.png'` (или `image: './assets/preview.gif'`).
3. Для фото профиля можно добавить в `index.html` элемент `<img src="./assets/me.jpg" alt="Моё фото">` в блок `.hero-copy`, а внешний вид настроить в `style.css`.

Поддерживаются PNG, JPG, SVG, WEBP и GIF. Лучше сжимать тяжёлые GIF, чтобы страницы не загружались слишком долго. Для GIF большого размера можно использовать видеофайл, но тогда понадобятся изменения в HTML.

## 4. Как поменять дизайн

Изменяйте файл **`style.css`**, в начале которого находятся основные переменные:

```css
:root {
  --bg: #0b0c10;      /* фон */
  --ink: #f4f4f0;     /* текст */
  --accent: #d9ff77;  /* яркий акцент */
  --lilac: #b5a0ff;   /* второй цвет */
}
```

Вы также можете заменить изображения `assets/project-pulse.svg`, `assets/project-north.svg` и `assets/project-mono.svg` на реальные скриншоты.

## 5. Структура файлов

```text
ВАШ_ЛОГИН.github.io/
├── index.html               # Структура сайта
├── style.css                # Вся стилизация и мобильная версия
├── config.js                # Имя, тексты, контакты, проекты и стек
├── script.js                # Меню, окно проекта, контакты, анимации
├── favicon.svg              # Иконка вкладки
├── .nojekyll                # GitHub Pages публикует файлы без Jekyll
├── README.md                # Эта инструкция
└── assets/
    ├── project-pulse.svg    # Демо-макет
    ├── project-north.svg    # Демо-макет
    └── project-mono.svg     # Демо-макет
```

## 6. Как проверить до публикации

Можно открыть `index.html` двойным нажатием на компьютере. Для полного тестирования удобнее открыть папку в редакторе VS Code и использовать расширение Live Server либо выполнить команду `python -m http.server 8000` из папки сайта, а затем открыть `http://localhost:8000`.

Создано как стартовый шаблон: текст, проекты, стек и контакты нужно адаптировать под ваш реальный опыт.
